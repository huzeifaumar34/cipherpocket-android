# Security policy

CipherPocket is designed to work offline and to keep operation data on the device.

Please do not publish sensitive plaintext, passwords, private keys, or encrypted personal files in public issues. For security-sensitive reports, use GitHub's private vulnerability reporting for this repository when available.

The initial M0 build is a development scaffold. It currently implements Base64 encoding/decoding only and must not be treated as a finished encryption product. AES-256-GCM, key derivation, file handling and the related security tests are later roadmap milestones.
